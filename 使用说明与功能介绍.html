⚡ 一、1 分钟快速上手（装好即玩，无需联网）

安装并打开桌宠后，小龙娘会直接出现在你的桌面上。无需注册账号，立刻可以体验以下互动：

你想做的操作 鼠标动作 效果说明
摸摸头互动 左键单击头顶区域 第 1 下眨眼害羞 → 第 2 下恢复气泡 → 第 3 下傲娇生气（30 秒后自动平复）
自由拖动位置 左键按住身体拖动 拖到屏幕任意角落；怕误碰可在「设置」打开锁定模型位置
唤出功能菜单 在小龙娘身上点右键 打开 💬 对话、切换角色、调节大小（30%–300%）、AI 设置、通用设置

💬 二、3 步接入 AI 聊天对话

小龙娘支持接入任意 OpenAI 兼容接口（DeepSeek、硅基流动、智谱 GLM、通义千问、Kimi、OpenAI、OpenRouter 或本地 Ollama）：

第 1 步 · 打开 AI 设置
在小龙娘身上点右键 → AI 设置，在顶部「供应商管理」点 + 添加，一键套用常用服务商模板或手动填入接口地址。
第 2 步 · 粘贴 API Key
填入你自己的 API Key（通过 Windows 系统级安全加密保存在本机，不会明文写入配置文件）。
第 3 步 · 选模型并保存
选择推荐模型或点击「拉取模型」，最后点面板底部的「保存」，回到右键菜单点 💬 对话即可开聊！

对话框里的宝藏功能

  • 流式打字 + 随时叫停：实时逐字回复，生成途中点击停止按钮即可立即中断请求。
  • 富文本与图表显示：支持代码语法高亮与复制、LaTeX 数学公式、提示卡片及 Mermaid 流程图渲染。
  • 识图截屏与文档解析：支持一键全屏截图（自动隐去桌宠自身）、粘贴图片，以及上传 PDF、Word (.docx)、Excel (.xlsx)、Markdown、代码文件 让小龙娘帮你总结分析。
  • 专属人设与多套技能：可在「AI 设置」中自由定制角色的称呼、性格与说话口吻，或切换不同场景的系统提示词。

🎙️ 三、语音输入（动嘴聊天）与语音朗读

打开 右键 → 设置 → 语音输入，支持云端 API 接口与本地离线模型两种语音转文字方案：

方案 A：连接 API 接口（推荐 · 自由选模型、免下离线包）

  1. 在「语音识别模型」卡片顶部点击 「连接 API 接口」。
  2. 在「快捷预设」中选择服务商（如硅基流动的 FunAudioLLM/SenseVoiceSmall、OpenAI 的 gpt-4o-mini-transcribe / whisper-1、Groq、智谱 GLM-ASR 或本地服务），也可点击「复用对话 API」直接带入对话接口地址与密钥，或手填任意兼容 /audio/transcriptions 的地址和模型名。
  3. 点击 「测试接口」，出现绿色 ✓ 接口连接可用 提示即自动保存生效！

方案 B：本地离线模型（Vosk · 断网可用）

  1. 保持在 「本地离线模型 (Vosk)」 标签，点击「导入小模型 ZIP」导入下载好的 Vosk 模型包（如 vosk-model-small-cn-0.22.zip）。
怎么开始说话？ 配置好上面任一方案后，打开正下方的 「对话框语音输入」 开关。随后打开聊天窗口点击 🎤 麦克风按钮，直接说话并自然停顿约 1 秒，文字就会自动识别并发送给小龙娘（再次点击 🎤 可取消本次录音）。

小龙娘语音回复（TTS 朗读）

  • 默认开启 「小龙娘语音回复」，直接使用 Windows 本地语音朗读回答，支持自定义音色、语速和音量。
  • 进阶用户也可在语音面板中指定本机 F5-TTS 克隆声资源目录，未就绪时会自动无缝回退系统语音。

🖥️ 五、运行环境说明与注意事项（新电脑必看）

1. 全新电脑可以直接用吗？

零额外环境依赖，装好即用！ 只要是 64 位 Windows 10 / Windows 11 电脑，直接运行安装包即可。安装包已自带完整的渲染引擎与内置运行时，普通用户无需安装 Node.js、Python、Java 或 .NET 环境，即可完整使用：3D 视差桌面互动（老旧显卡不支持 WebGL 时会自动平滑降级为高清静态原画兜底，绝不白屏）、AI 聊天、截屏识图、PDF/Word/Excel/代码文档解析、API 语音识别与 Vosk 离线语音输入、Windows 系统自带语音朗读，以及内置本地文件系统工具。

2. 仅在开启以下「高阶可选扩展」时，才需额外准备

以下均为默认关闭的可选项，不配置也完全不影响日常陪伴与聊天：

可选高阶功能 需要额外准备的环境或文件 未准备时的自动表现
F5-TTS 本地克隆声朗读 本机需自备 Python + PyTorch + f5_tts 环境及参考音频权重（建议配备独立显卡） 自动无缝回退到 Windows 系统自带语音朗读，不会报错
第三方外部 MCP 插件 若手动添加通过 npx 或 uvx 拉取的社区插件，电脑需安装 Node.js 或 Python/uv 不影响日常对话和桌宠内置的文件系统工具
导入 Live2D 角色 无需装编程环境，但需从官方免费获取 live2dcubismcore.min.js 放入桌宠 Live2D 资源目录 默认小龙娘与 Hatch-Pet 角色完全正常使用
本地大模型（Ollama 等） 若不走云端 API 而改连本机大模型 / 本地 Whisper，需自行启动对应本地服务 使用云端 API Key 时无需任何本机模型服务
修改源码重新编译打包 仅开发者修改 Source.zip 源码重新打包时，需安装 Node.js 22 或 24 普通使用者直接运行 Setup.exe，无需安装

3. 安装与使用注意事项

• 首次安装蓝框提示（Windows SmartScreen）：由于个人开源软件未购买商业数字签名证书，新电脑首次运行安装程序若弹出蓝色的「Windows 已保护你的电脑」提示，点击弹窗里的 「更多信息」→「仍要运行」 即可正常安装。
• 麦克风系统权限：使用语音输入前，请确认 Windows「设置 → 隐私和安全性 → 麦克风」中已开启“允许桌面应用访问你的麦克风”。
• 网络与代理：AI 对话与 API 语音识别会自动遵循当前系统的网络与代理配置；纯桌面互动、Vosk 离线听写与系统朗读无需联网。

❓ 六、常见问题速查（FAQ）

1. 小龙娘被拖到副屏或屏幕边缘找不到了怎么办？

左键或右键点击右下角任务栏托盘图标选「显示桌宠」，或者重启一次程序，桌宠会自动校准屏幕边界并回到可见区域内。

2. 为什么打开对话框后没看到 🎤 语音按钮？

请确认已在「右键 → 设置 → 语音输入」中打开了「对话框语音输入」开关，并在上方的「语音识别模型」中配好了 API 接口或导入了 Vosk 模型。

3. 我的 API Key 和聊天记录保存在哪里？重装会丢吗？

配置、记忆与导入的角色保存在本机 %APPDATA%\XiaolongniangDesktopPet 目录，覆盖升级不会丢失；所有 API Key 均经由 Windows 系统凭据加密存储，安全可靠。

4. 以后想再看这份说明怎么找？

这份说明已随安装包一并保存在桌宠安装目录中（使用说明与功能介绍.html），你也可以随时通过右下角托盘右键菜单或设置面板底部按钮一键打开！
